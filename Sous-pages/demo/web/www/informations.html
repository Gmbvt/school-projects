Site

Ce site reprend le fonctionnement du jeu Hearts of Iron IV, jeu vidéo de grande stratégie dont l'éditeur (Paradox) est crédité dans le pied de page de cette page. Ce jeu se déroule habituellement au cours de la seconde guerre mondiale (1936-1949), le joueur pouvant changer le cours de l'Histoire par ses actions. Notre site ne reprend cependant pas ce scénario et se base sur un univers complètement différent, inventé pour se détacher du jeu original. Ce site a été crée par Guillaume BEUVOT et Enzo BOUCHE, étudiants de Prep'ISIMA 2.

Contenu

Ce site contient, à l'instar du jeu, un menu, un sélecteur de pays majeurs avec un menu cliquable (MENU -> Pays Majeurs), donnant des information sur ces derniers (nom, drapeau, description, drigeant).
Il contient aussi une liste complète des pays (MENU -> Liste Pays), cliquable aussi et donnant aussi des informations sur ces derniers. Il contient une page expliquant le contexte historique du scénario (MENU -> Histoire), ainsi que des cartes de l'univers de ce site . Il contient aussi un formulaire (MENU -> formulaire).

Fonctionnalités

Ce site, réalisé dans le cadre du projet Technologie de Web - Côté Client, doit répondre à certaines contraintes imposées. Ces contraintes ont été implémentées sur différentes pages à travers ce site :

  • Intégrer plusieurs types de balises (HTML) : Ce site utilise plusieurs balises html, conteneurs et textuels
  • Organiser en paragraphes (HTML) : Cette page même, tout comme la page histoire sont organisées en paragraphes avec des balises strong ou b et em ou i
  • Intégrer une liste (HTML) : Ce contenu est lui-même présent dans une liste
  • Intégrer une image avec une légende (HTML) : La (les) carte(s) sont des images liées avec une légende
  • Intégrer un tableau avec les balises adaptées (HTML) : Un tableau est présent dans la page de la liste complète des pays
  • Intégrer des balises Open Graph (HTML) : Des balises donnant le nom du site, le titre de la page courante ainsi qu'une breve description de ce qu'elle contient sont présentes sur l'ensemble des pages.
  • Intégrer des liens hypertextes (HTML) : Le pied de page de cette page (et du site) contient un lien vers un site externe (paradoxinteractive.com), un lien vers le menu, un lien vers le haut de la page (sur la page du menu), et des liens sur des parties/chapitres de texte (pages informations/histoires)
  • Utiliser une balise myreset.css et une balise commun.css (CSS) : Cela est présent sur le site
  • Adapter la taille du contenu en fonction de la taille de la fenêtre (CSS) : Cela est présent sur le site
  • Utiliser des transitions (CSS) : Présent sur le site (pied de page)
  • Utiliser des media queries pour adapter la visibilité du site en fonction de différents appareils : Ce site est adapté, grâce à cette fonctionnalitée, aux écrans d'ordinateur, de téléphone (en mode portrait) et de tablette (en mode paysage)
  • Adapter la visibilité du site en fonction des différents handicaps visuels possibles : ce site a été créé pour être visible par tous les types de daltonisme et tous les types de problème de contraste
  • Intégrer un formulaire (Javascript / Ecmascript) : Présent dans la page Formulaire
  • Faire fonctionner le formulaire avec un serveur python (Javascript/Ecmascript et python) : Cela a été implémenté avec le formulaire

Remarques

A propos des variables css

Il y a quelques repetitions au niveau des pages css, nottament au niveau de la gestion des couleurs et du dynamisme de la barre de naviguation de bas de page. Cela devrait pouvoir être limiter en se servant de commun.css et en uniformisant les couleurs de chaque pages (ici on a plusieurs pages en blanc, d'autres en noire, d'autre avec du vert ...). On pourrait alors penser à utiliser les variables css de couleurs pour gerer un mode nuit/jour.

A propos des Media Queries

Les media queries sont à geométrie variable. Si le menu est assez bien pensé et adapté pour une utilisation sur téléphone ce n'est pas le cas des pages listes pays et pays majeurs. Il faudrait peut être revoir totalement ces pages ci pour les rendres plus adaptable. Pour l'instant elles sont surtout pensées pour une utilisation pc et aurrait peut être du, avant implémentation, être pensées pour chaque utilisations voulues de ce site.
